LearnKit

Dependency-free Web Components for learning content, with themes you can swap and customise. No framework and no build step.

Try it

  • Examples

    Every component on one page, with plain markup you can copy.

  • Theme gallery

    One component in every theme, or one theme with every component. Light, dark or system.

  • Customiser

    Start from a theme, change colours, shape and fonts, check contrast and export the CSS.
